## Présentation

Interface web pour explorer et modifier une base MongoDB : lister les collections, créer, éditer et supprimer des documents sans passer par un client lourd.

**Pourquoi ce choix.** Sur un petit projet, installer Compass pour corriger trois documents est disproportionné. Une page servie par l'API suffit.

---

## Ce que fait le projet

- Opérations **CRUD** complètes sur les documents
- Interface d’une seule page, servie par le serveur
- Connexion configurée par variable d’environnement
